# 1. BFS on Disconnected Graph ⭐⭐⭐⭐⭐

## Problem

A graph may consist of multiple disconnected components.

Example:

```
Component 1        Component 2

     0                4
    / \              / \
   1   2            5   6
        \
         3
```

If BFS starts from node `0`, the traversal will be:

```
0 → 1 → 2 → 3
```

Nodes `4, 5, 6` are never visited.

---

## Why Doesn't Normal BFS Work?

A standard BFS explores **only the connected component** containing the source vertex.

Therefore, an outer loop is required to ensure that every vertex in the graph is processed.

---

## Algorithm

1. Create a `visited[]` array.
2. Traverse all vertices from `0` to `V - 1`.
3. If a vertex is unvisited:
    - Start BFS from that vertex.
4. Repeat until all vertices are visited.

---

## Java Code

```
import java.util.*;

public class BFSDisconnected {

    static void bfs(int src,
                    List<List<Integer>> graph,
                    boolean[] visited) {

        Queue<Integer> queue = new LinkedList<>();

        visited[src] = true;
        queue.offer(src);

        while (!queue.isEmpty()) {

            int current = queue.poll();

            System.out.print(current + " ");

            for (int neighbour : graph.get(current)) {

                if (!visited[neighbour]) {

                    visited[neighbour] = true;
                    queue.offer(neighbour);
                }
            }
        }
    }

    public static void bfsTraversal(List<List<Integer>> graph) {

        boolean[] visited = new boolean[graph.size()];

        for (int i = 0; i < graph.size(); i++) {

            if (!visited[i]) {

                bfs(i, graph, visited);

            }
        }
    }
}
```

---

## Dry Run

|i|Visited?|Action|Output|
|---|---|---|---|
|0|No|BFS(0)|0 1 2 3|
|1|Yes|Skip||
|2|Yes|Skip||
|3|Yes|Skip||
|4|No|BFS(4)|4 5 6|

Final Traversal

```
0 1 2 3 4 5 6
```

---

# Interview Tip ⭐⭐⭐⭐⭐

**Q:** Why is the outer loop required?

**Answer:**

> A normal BFS visits only the connected component containing the source. The outer loop ensures every disconnected component is traversed.

# 2. Level Order BFS ⭐⭐⭐⭐⭐

This variation processes the graph **level by level**.

---

## Example

```
          0
       /     \
      1       2
    /  \     /
   3    4   5
```

Levels

```
Level 0 → 0

Level 1 → 1 2

Level 2 → 3 4 5
```

---

## Why Do We Need Levels?

Many interview problems require:

- Minimum time
- Minimum moves
- Number of levels
- Tree level traversal
- Rotten Oranges
- Word Ladder

---

## Trick

Store

```
int size = queue.size();
```

before processing the current level.

---

## Java Code

```
import java.util.*;

public class LevelOrderBFS {

    static void bfsLevel(int source,
                         List<List<Integer>> graph) {

        boolean[] visited = new boolean[graph.size()];

        Queue<Integer> queue = new LinkedList<>();

        queue.offer(source);
        visited[source] = true;

        int level = 0;

        while (!queue.isEmpty()) {

            int size = queue.size();

            System.out.print("Level " + level + ": ");

            for (int i = 0; i < size; i++) {

                int current = queue.poll();

                System.out.print(current + " ");

                for (int neighbour : graph.get(current)) {

                    if (!visited[neighbour]) {

                        visited[neighbour] = true;
                        queue.offer(neighbour);

                    }
                }
            }

            System.out.println();

            level++;

        }

    }

}
```

---

## Dry Run

|Level|Queue Before|Nodes Processed|Queue After|
|---|---|---|---|
|0|[0]|0|[1,2]|
|1|[1,2]|1,2|[3,4,5]|
|2|[3,4,5]|3,4,5|[]|

---

# Interview Tip

The queue size at the start of each iteration equals the number of nodes in the current level.

# 3. Shortest Path in Unweighted Graph ⭐⭐⭐⭐⭐

One of the most frequently asked BFS questions.

---

## Why BFS?

Because BFS explores nodes level by level.

The first time a node is reached, it is guaranteed to be through the shortest path (minimum number of edges).

---

## Example

```
      0
    /   \
   1     2
  / \     \
 3   4-----5
```

Shortest Distance from 0

|Vertex|Distance|
|---|---|
|0|0|
|1|1|
|2|1|
|3|2|
|4|2|
|5|2|

---

## Algorithm

Maintain

```
distance[]
```

Initially

```
distance = -1
```

Source

```
distance[source]=0
```

Whenever visiting a neighbour

```
distance[neighbour]
=
distance[current]+1
```

---

## Java Code

```
import java.util.*;

public class ShortestPathBFS {

    static void shortestPath(int source,
                             List<List<Integer>> graph) {

        int[] distance = new int[graph.size()];

        Arrays.fill(distance, -1);

        Queue<Integer> queue = new LinkedList<>();

        queue.offer(source);

        distance[source] = 0;

        while (!queue.isEmpty()) {

            int current = queue.poll();

            for (int neighbour : graph.get(current)) {

                if (distance[neighbour] == -1) {

                    distance[neighbour]
                            = distance[current] + 1;

                    queue.offer(neighbour);

                }

            }

        }

        System.out.println(Arrays.toString(distance));

    }

}
```

Output

```
[0,1,1,2,2,2]
```

---

## Dry Run

|Current|Distance|Newly Updated|
|---|---|---|
|0|0|1=1, 2=1|
|1|1|3=2, 4=2|
|2|1|5=2|
|3|2|-|
|4|2|-|
|5|2|-|

---

# Interview Tip

BFS gives the shortest path **only for unweighted graphs** (or graphs where every edge has equal weight). For weighted graphs with different edge weights, use algorithms such as Dijkstra's or Bellman–Ford.

# 4. Multi-Source BFS ⭐⭐⭐⭐⭐

Very popular in interviews.

---

## Difference

Normal BFS

```
Queue

↓

One Source
```

---

Multi-Source BFS

```
Queue

↓

Many Sources
```

---

## Applications

- Rotten Oranges
- 01 Matrix
- Walls and Gates
- Fire Spread
- Virus Spread

---

## Example

```
Sources

0     5
```

Both start simultaneously.

---

## Algorithm

Instead of adding one source

```
queue.offer(source);
```

Add every source

```
queue.offer(allSources);
```

Then perform normal BFS.

---

## Generic Java Code

```
import java.util.*;

public class MultiSourceBFS {

    static void multiSource(List<Integer> sources,
                            List<List<Integer>> graph) {

        boolean[] visited = new boolean[graph.size()];

        Queue<Integer> queue = new LinkedList<>();

        for (int source : sources) {

            queue.offer(source);

            visited[source] = true;

        }

        while (!queue.isEmpty()) {

            int current = queue.poll();

            System.out.print(current + " ");

            for (int neighbour : graph.get(current)) {

                if (!visited[neighbour]) {

                    visited[neighbour] = true;

                    queue.offer(neighbour);

                }

            }

        }

    }

}
```

# Time Complexity

All four BFS variations have the same complexity.

|Operation|Complexity|
|---|---|
|BFS Traversal|O(V + E)|
|Disconnected Graph|O(V + E)|
|Level Order BFS|O(V + E)|
|Shortest Path|O(V + E)|
|Multi-Source BFS|O(V + E)|

Space Complexity

```
O(V)
```

# Common Mistakes

❌ Forgetting the outer loop for disconnected graphs.

❌ Marking nodes as visited after dequeueing instead of before enqueueing.

❌ Using BFS shortest path on weighted graphs with different edge weights.

❌ Forgetting to initialize all source nodes in Multi-Source BFS.

---

# Most Asked Interview Questions ⭐⭐⭐⭐⭐

### 1. Why does BFS fail on disconnected graphs?

Because it explores only the connected component containing the starting vertex. An outer loop is needed to start BFS from each unvisited vertex.

---

### 2. Why do we use `queue.size()` in Level Order BFS?

It represents the number of nodes at the current level, allowing us to process one level completely before moving to the next.

---

### 3. Why is BFS used for shortest paths in unweighted graphs?

Because BFS visits vertices in increasing order of distance (number of edges). The first time a vertex is visited is always through the shortest path.

---

### 4. What is Multi-Source BFS?

It is a BFS that starts from multiple source vertices simultaneously by inserting all sources into the queue initially. This models scenarios where several starting points expand at the same time.

---

### 5. Give real interview problems based on these variations.

- **Disconnected BFS:** Traverse all graph components.
- **Level Order BFS:** Binary tree level order traversal, minimum time problems.
- **Shortest Path BFS:** Shortest path in an unweighted graph, Word Ladder.
- **Multi-Source BFS:** Rotten Oranges, 01 Matrix, Walls and Gates, fire/virus spread simulation.
