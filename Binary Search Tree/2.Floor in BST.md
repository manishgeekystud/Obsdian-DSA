Given the **root** of a **[binary search tree](https://www.geeksforgeeks.org/binary-search-tree-data-structure/ "BST")** and a number **k**, find the **greatest** number in the binary search tree that is less than or equal to **k**.

**Note:** If no such node value exists that is smaller than _k_, then return **-1**.

**Examples:**

**Input:** root = [10, 7, 15, 2, 8, 11, 16],  k  =  14  
![](https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/895571/Web/Other/blobid3_1747652897.jpg)  
**Output:** 11
**Explanation:** The greatest element in the tree which is less than or equal to 14, is 11.

**Input:** root = [5, 2, 12, 1, 3, 9, 21, N, N, N, N, N, N, 19, 25],  k  = 24  
![](https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/895571/Web/Other/blobid0_1747652607.jpg)  
**Output:** 21
**Explanation:** The greatest element in the tree which is less than or equal to 24, is 21.
