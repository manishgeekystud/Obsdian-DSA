# Problem Statement

Given the root of a **Binary Search Tree (BST)** and an integer **K**, find the **Kth smallest element**.

---

# Example

```
              5
            /   \
           3     7
         /  \   / \
        2   4  6   8
```

Inorder Traversal

```
2 3 4 5 6 7 8
```

If

```
K = 3
```

Answer

```
4
```

---

# Why Inorder?

The most important BST property:

```
Inorder Traversal of BST

=

Sorted Order
```

Example

```
        20
       /  \
      10   30
     / \   / \
    5 15 25 35
```

Inorder

```
5 10 15 20 25 30 35
```

Therefore,

- 1st Smallest → First node visited
- 2nd Smallest → Second node visited
- kth Smallest → kth node visited

# Approach 1 (Brute Force)

## Idea

1. Perform inorder traversal.
2. Store elements in an ArrayList.
3. Return

```
list.get(k-1)
```

---

## Algorithm

```
Inorder Traversal

↓

Store in ArrayList

↓

Return list[k-1]
```

---

## Code

```java
class Solution {

    ArrayList<Integer> list = new ArrayList<>();

    public int kthSmallest(Node root, int k) {

        inorder(root);

        return list.get(k - 1);
    }

    void inorder(Node root) {

        if (root == null)
            return;

        inorder(root.left);

        list.add(root.data);

        inorder(root.right);
    }
}
```

# Approach 2 (Optimal DFS)

Instead of storing every element,

count nodes during inorder traversal.

---

## Idea

Every time a node is visited,

increase count.

When

```
count == k
```

Current node

=

Answer.

---

# Algorithm

```
Go Left

↓

Visit Node

↓

count++

↓

count==k ?

↓

Yes

Store Answer

↓

Go Right
```

---

## Code

```java
class Solution {

    int count = 0;
    int ans = -1;

    public int kthSmallest(Node root, int k) {

        inorder(root, k);

        return ans;
    }

    void inorder(Node root, int k) {

        if (root == null)
            return;

        inorder(root.left, k);

        count++;

        if (count == k) {
            ans = root.data;
            return;
        }

        inorder(root.right, k);
    }
}
```

# Early Stopping Optimization

Once answer is found,

no need to continue.

```java
class Solution {

    int count = 0;
    int ans = -1;

    public int kthSmallest(Node root, int k) {

        inorder(root, k);

        return ans;
    }

    void inorder(Node root, int k) {

        if (root == null || ans != -1)
            return;

        inorder(root.left, k);

        if (ans != -1)
            return;

        count++;

        if (count == k) {
            ans = root.data;
            return;
        }

        inorder(root.right, k);
    }
}
```

This avoids unnecessary traversal after the answer is found.

# Approach 3 (Iterative Inorder Using Stack)

This is a favorite interview approach because it avoids recursion.

---

## Code

```
class Solution {

    public int kthSmallest(Node root, int k) {

        Stack<Node> stack = new Stack<>();

        while (root != null || !stack.isEmpty()) {

            while (root != null) {
                stack.push(root);
                root = root.left;
            }

            root = stack.pop();

            k--;

            if (k == 0)
                return root.data;

            root = root.right;
        }

        return -1;
    }
}
```

---

## Why Does It Work?

The stack simulates recursion.

The nodes are visited in

```
Left

↓

Root

↓

Right
```

which is the inorder traversal of a BST.

# Approach 4 (Morris Traversal - Most Optimized)

Uses threaded binary trees.

Extra space

```
O(1)
```

Time

```
O(N)
```

This is considered an advanced interview solution.

---

## Morris Traversal Code

```
class Solution {

    public int kthSmallest(Node root, int k) {

        Node curr = root;

        while (curr != null) {

            if (curr.left == null) {

                if (--k == 0)
                    return curr.data;

                curr = curr.right;
            } else {

                Node pred = curr.left;

                while (pred.right != null && pred.right != curr)
                    pred = pred.right;

                if (pred.right == null) {

                    pred.right = curr;
                    curr = curr.left;

                } else {

                    pred.right = null;

                    if (--k == 0)
                        return curr.data;

                    curr = curr.right;
                }
            }
        }

        return -1;
    }
}
```

# Common Mistakes

### Mistake 1

Using preorder traversal.

Wrong.

Only inorder gives sorted order in a BST.

---

### Mistake 2

Returning

```
list.get(k);
```

Correct

```
list.get(k-1);
```

ArrayList uses **0-based indexing**.

---

### Mistake 3

Not stopping after finding the answer.

Continue traversing unnecessarily.

Use early stopping.

---

### Mistake 4

Applying this logic to a normal Binary Tree.

The inorder traversal of a normal binary tree is **not sorted**.

---

# Interview Questions

### 1. Why does inorder traversal return sorted order in a BST?

Because every node satisfies the BST property:

- Left subtree values < Root
- Right subtree values > Root

Therefore, Left → Root → Right naturally visits nodes in ascending order.

---

### 2. Which approach is most preferred in interviews?

The **recursive counter** or the **iterative stack** approach. They avoid storing all elements and use only `O(H)` extra space.

---

### 3. Which approach uses the least extra space?

**Morris Traversal**, with `O(1)` auxiliary space.

---

### 4. What if the tree is not a BST?

The inorder traversal is not guaranteed to be sorted, so this approach will not work. You would need a different algorithm, such as traversing all nodes and using a heap or sorting.
