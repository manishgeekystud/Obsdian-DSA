Dynamic Method Dispatch, also known as **runtime polymorphism**, is a mechanism in object-oriented programming where the method to be executed is determined at runtime rather than compile time. This feature is central to achieving polymorphism in Java and allows for flexibility and extensibility in code.

When a subclass overrides a method from its superclass, the overridden method is executed based on the **actual type of the object** being referred to, not the type of the reference variable. This is achieved through **upcasting**, where a superclass reference variable refers to a subclass object.

Syntax and Example

Here is an example to demonstrate dynamic method dispatch:
```java
class A {
   void m1() {
       System.out.println("Inside A's m1 method");
   }
}
class B extends A {
   void m1() {
       System.out.println("Inside B's m1 method");
   }
}
class C extends A {
   void m1() {
       System.out.println("Inside C's m1 method");
   }
}
public class Dispatch {
   public static void main(String[] args) {
       A a = new A(); // Object of type A
       B b = new B(); // Object of type B
       C c = new C(); // Object of type C
       A ref; // Reference of type A
       ref = a;
       ref.m1(); // Calls A's m1 method
       ref = b;
       ref.m1(); // Calls B's m1 method
       ref = c;
       ref.m1(); // Calls C's m1 method
   }
}

```
**Output**:

Inside A's m1 method
Inside B's m1 method
Inside C's m1 method

**Explanation**:

- The _ref_ variable is of type _A_ but refers to objects of types _A_, _B_, and _C_ at different points.
- The method _m1()_ executed depends on the **actual type of the object** (_A_, _B_, or _C_) that _ref_ refers to at runtime.

# What is Downcasting?

**Downcasting** is the process of converting a **parent class reference** into a **child class reference**.
It allows you to access the child-specific methods and fields.

**Syntax**

```
Child childRef = (Child) parentRef;
```
The cast is **explicit**, meaning you must write it yourself.

---

# Why is Downcasting Needed?

Suppose a child class has methods that the parent class doesn't.

```
class Animal {
    void eat() {
        System.out.println("Animal eats");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks");
    }
}
```

Now create an object using upcasting:

```
Animal a = new Dog();
```

You can call:

```
a.eat();
```

But this won't compile:

```
a.bark();   // Compile-time error
```

Why?

Because the **reference type** is `Animal`, and `Animal` doesn't have a `bark()` method.

To access `bark()`, you need downcasting.

```
Dog d = (Dog) a;

d.bark();
```

Output

```
Dog barks
```
